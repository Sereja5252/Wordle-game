Описание проекта
Суть моего проекта заключается в создании консольной игры Wordle с русскими словами и возможностью выбора уровня сложности(разного количества букв в слове).


Реализуемый функционал
Выбор длины слова: пользователь может выбрать количество букв в загаданном слове.
Генерация случайного слова: приложение рандомно выбирает слово из списка русских слов заданной длины.
Ввод догадок: пользователь вводит свои предположения о том, что за слово было загадано.
Обратная связь с пользователем: после каждой попытки пользователь получает подсказки, связанные с угаданными буквами в слове:
 1) Буквы, которые находятся на правильных местах.
 2) Буквы, которые присутствуют в слове, но находятся на других позициях.
Ограничение попыток: количество попыток в игре ограничено и зависит от длины загаданного слова.
Итог игры: программа покажет пользователю загаданное слово и выведет сообщение о том, было ли угадано слово или нет.


Архитектура
1. Класс, отвечающий за основную логику игры.
Атрибуты:
длина слова
загаданное слово
максимальное количество попыток
текущий номер попытки
индикатор окончания игры 
список доступных слов

Методы:
инициализация игры 
запуск новой игры
проверка догадки
проверка состояния игры(завершена или нет)

2. Класс для работы со списком слов
Атрибуты:
длина слова 
список слов заданной длины

Методы:
загрузка списка слов
чтение слов из файла
выбор случайного слова

3. Класс для управления интерфейсом пользователя
Методы:
отображение главного меню
получение ввода от пользователя 
отображение подсказок
отображение итогового результата 
запуск цикла игры
